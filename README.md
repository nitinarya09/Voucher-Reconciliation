# IFMIS–VLC Voucher Reconciliation Tool
### Desktop Financial Audit Application (Python Backend + PyWebView UI)

---

## 1. Executive Summary & Statutory Purpose
The **IFMIS–VLC Voucher Reconciliation Tool** is an enterprise-grade desktop utility designed for Government Accounts Offices, Treasuries, and AG Audit establishments. It performs automated, exact-rupee ($\Delta = ₹0.00$) reconciliation between:
1. **Electronic Schedule of Payments (SOP) exports** generated by the State IFMIS Treasury Portal.
2. **Gross voucher compilation datasets (COMPAY)** extracted from the VLC database of posted vouchers.

---

## 2. Supported Input Files (The Six Files)

| File | Source | Format | Contents | Role in Reconciliation |
| :--- | :--- | :--- | :--- | :--- |
| **File 1** | IFMIS Portal | Delimited Text (`.txt`/`.csv`) | Gross, Net, AG Ded, Try Ded | Master bill-level arithmetic check (`Gross = Net + AG Ded`) |
| **File 2** | IFMIS Portal | Delimited Text (`.txt`/`.csv`) | Detailed 15-digit Classification | Primary Gross Amount comparison against COMPAY |
| **File 3** | IFMIS Portal | Delimited Text (`.txt`/`.csv`) | AG Deductions (GPF, Recoveries) | Itemized analysis of GPF (`8009`), Recoveries (`0070`), Loans (`7610`) |
| **File 4** | IFMIS Portal | Delimited Text (`.txt`/`.csv`) | Treasury Deductions (Non-AG) | Analysis of Suspense/TDS (`8658`), PT (`0028`), GIS (`0216`) |
| **File 5** | IFMIS Portal | Delimited Text (`.txt`/`.csv`) | Net Payment Vouchers (SOP) | Separate Net Amount reconciliation against File 1 Net |
| **File 6** | VLC Database | TSV / Excel (`.XLS`/`.tsv`) | Gross Amount of Posted Vouchers | Authoritative reference dataset for Gross Amount reconciliation |

## 4. Key Accounting Findings Documented

1. **Internal SOP Parity**:
   * $\sum \text{File 1 Gross} = \sum \text{File 2 Sum} = ₹64,96,41,89,762.00$
   * $\sum \text{File 1 AG\_DED} = \sum \text{File 3 Sum} = ₹9,19,20,025.00$
   * $\sum \text{File 1 TRY\_DED} = \sum \text{File 4 Sum} = ₹9,76,17,19,836.00$
   * $\sum \text{File 1 Net} = \text{Gross} - \text{AG\_DED} = \sum \text{File 5} = ₹64,87,22,69,737.00$
2. **Missing Capital Vouchers (MH 4801)**:
   * Vouchers 37, 38, 39 of Major Head `4801` (totaling ₹1,250 Crores) are present in VLC COMPAY (dated 14-10-2025) but omitted from the Treasury SOP export (which jumps from Voucher 36 to 40).
3. **GPF Deductions Consolidation (MH 8009)**:
   * $\sum \text{File 2 Direct GPF (₹22,94,51,267)} + \sum \text{File 3 GPF Deductions (₹9,17,61,773)} = \mathbf{₹32,12,13,040}$ (Exact match with COMPAY MH 8009).
4. **Administrative Recoveries Netted (MH 0070)**:
   * Recoveries under Profession Tax and MH 0070 are netted from voucher gross in COMPAY, perfectly explaining the 214 adjusted vouchers.
5. **Uncompiled Public Account Heads**:
   * Heads `8011` (GIS), `8342` (Deposits/NPS), and `8658` (Suspense) totaling ₹20.86 Crores are handled outside consolidated fund payments.

## 7. Supported Export Formats

1. **Excel Workbook (`.xlsx`)**:
   * 13 worksheets: *Grand Tally Balance Sheet*, *Gross Recon (F2 vs F6)*, *Matched Vouchers*, *Missing Vouchers Exceptions*, *Cross-File Consistency Checks*, *Major Head Tally*, *Transfer Entries*, and *Processing History*.
   * Formatted headers, frozen panes, filters, exact currency formatting.
2. **Formal PDF Report (`.pdf`)**:
   * ReportLab landscape audit report with executive tables, repeating headers, page numbers, and sign-off blocks.
3. **CSV Dataset (`.csv`)**:
   * Clean UTF-8 with BOM export preserving leading zeroes and text identifiers.
4. **Plain Text Audit Summary (`.txt`)**:
   * Complete ASCII executive summary and balance sheet statement.
